About PhantomPrint

Version: 1.0.0

License: MIT


PhantomPrint protects against browser fingerprinting by spoofing, randomizing, and blocking over 200 fingerprinting parameters across 20 categories.


Features:

  • Deterministic per-site fingerprints (cross-site unlinkability)
  • Consistent spoofed values that pass detection tests
  • Profile management (save/load/import/export)
  • Per-site whitelist support
  • Anti-detection measures (native function signatures, prototype chain preservation)
