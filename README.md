# PhantomPrint v4.0

Advanced browser fingerprint protection extension for Chrome (Manifest V3).

## Features
- Complete A-Z Fingerprint Spoofing: Canvas, WebGL, Audio, Navigator, Screen, Fonts, WebRTC, Timezone, Client Rects, Battery, Speech, Media, Storage, Timing
- 25+ Realistic Device Profiles covering Windows, macOS, Linux, Android, iOS
- One-Click Randomization with session-consistent seeded PRNG
- Anti-Detection Stealth: toString() masking, native property descriptors
- Auto-Rotate via chrome.alarms, Per-Site Profiles, Domain Whitelist
- Profile Export/Import as JSON, Header Modification via declarativeNetRequest
- Noise Calibration (Low/Medium/High), Protection Dashboard with score

## Installation
1. Open Chrome -> chrome://extensions/
2. Enable Developer mode
3. Click Load unpacked -> select PhantomPrint folder

## Privacy
PhantomPrint runs entirely locally. No data is sent to any server.
